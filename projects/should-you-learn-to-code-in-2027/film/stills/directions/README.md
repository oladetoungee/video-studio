## B · YOU ARE THE REVIEWER (`B-review/`), recommended
**Idea.** AI writes the code and you review it. Every example in the video is ONE review sheet that changes as you talk.
Removed lines are red, added lines are green, and your review note is amber. Amber always means "you, the human".
Even the parts without code are reviews:
- the Indeed numbers are a page you read, with your note on it;
- the four skills are a change to the syllabus: `- learn syntax`, `- learn to write a for loop`, then `+ reading code`,
  `+ debugging`, `+ fundamentals`, `+ a little system design`, `+ domain knowledge`;
- the verdict is your approval: "I think it's still worth it."

- **Video type:** talking head + receipts (playbook #07, #08, #21) with a code explainer that follows one running example
  (#03, #25: the same sign-up code all through debugging). Your examples were already code (the sign-up crash, the payment
  webhook), and this look shows exactly what you are saying: "you add the human in the loop."
- **Look.**
  - Colours: cool grey ground `#E9EBEE`, white sheets with a 3 px ink border `#1B1F24`, flat, no shadows, no rounded
    corners. Diff green `#1A7F37` on `#DDF6E3`, red `#CF222E` on `#FFE4E1`. ONE accent: amber `#F2A900`, only for you.
  - Type: Onest 800 for headlines and Martian Mono for code. Code is at least 46 px at 1920 wide (40 px at 1080). Labels
    are at least 32 px.
  - Grid: a headline row, the sheet on the left (x 110-1260) and a side column (x 1320-1810).
- **Motion in numbers.**
  - Code lines type on at 40 characters a second, on your words.
  - A removed line gets struck through in 0.3 s.
  - Your amber note drops 26 px in 0.4 s.
  - Sheets slide up 60 px in 0.45 s.
  - Every hold gets a slow 2 % push, so nothing sits still for more than about 3 s.
- **Signature transitions.** A hard cut on your word, then the sheet changes (strike, then type on). The error bar
  disappears when "the crash goes away".
- **Talking-head edit.**
  - The review sheet hangs on the plain wall to your left, so it never covers your face (`th3`, `th5`).
  - Captions are C2: white bold caps with one word on an amber box.
- **Shorts.** Top title T3 is an amber box with Onest. Under it, the real page (T9) or the code window, then you in a
  4:5 window, with C2 captions. No timers.
- **Correction in the edit** (your rule): `b8`. You say "we found out … about 15% between February last year to June this
  year". A plain screen types on: "Indeed found this, not me. US software development postings: up almost 15%. Late
  February 2025 to June 2026." The real Indeed line sits underneath.
- **Sound roles.** Typewriter click (a line types on), marker (the strike), typewriter hit (added lines), small glitch
  (the crash disappears), UI select (the status bar), message pop (your note). No whooshes.
- **Files.** `frames/b1`-`b7` (16:9), `b8` (correction), `p1`, `p2` (9:16), `motion-test.mp4` (raw 2:52.4 to 3:02.3,
  the try-catch line).

## How these were made (to re-render)
- **Pages:** `<look>/index.html`. Each is a plain canvas, and every frame is a pure function of time. Shared files:
  `_shared/lib.js`, `fonts.css`, `clips.js` (made by `_tools/clips.py` from the captured pages in `_src/`).
- **Stills:** `node _tools/r.mjs shots B-review/index.html 1920x1080 b1 b2 …` (and `1080x1920 p1 p2`). The
  talking-head and shorts frames come from `talking-head/index.html`.
- **Motion test:** `node _tools/r.mjs video B-review/index.html 1920x1080 172.4 182.3 B-review/_silent.mp4`, then
  `python3 _tools/mixtest.py B-review 172.4 182.3 B-review/_silent.mp4 B-review/motion-test.mp4`. The cues are in
  `sounds.json`.
- **Overview:** `python3 _tools/overview.py`.
- Once you pick, the look gets rebuilt in the studio engine (film + talking-head layouts), so everything can be edited
  there.
