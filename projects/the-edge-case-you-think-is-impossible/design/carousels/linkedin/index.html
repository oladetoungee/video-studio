2 · Race condition
1 left, 2 sold
UPDATE products SET stock = stock - 1 WHERE id = 42 AND stock > 0 -- 0 rows updated = sold out

If two requests arrive at the same time, only one of them can take the last item. The other one gets zero rows updated. In 2015 a researcher used this kind of bug to turn $15 of Starbucks gift cards into $20.

3 · Names
The name O'Brien can break your query
Surname
O'Brien
!The apostrophe breaks the SQL query

The apostrophe is the character that starts and ends text in SQL. If your code glues the name straight into the query, it breaks. The BBC also wrote about Jennifer Null, whose surname gets read as empty.

4 · NULL
A licence plate that said NULL got $12,000 in fines
WIRED, Brian Barrett, 13 Aug 2019

Security researcher Joseph Tartaro told the story at DEF CON in 2019. Tickets with no plate on them ended up with his name, because the system read NULL as a plate.

8 · Hyrum's law
Whatever your API does, someone depends on it
With a sufficient number of users of an API, it does not matter what you promise in the contract: all observable behaviors of your system will be depended on by somebody.
Hyrum's law, named after Hyrum Wright

If your API always returned a list in the same order, someone's code now depends on that order, even though you never promised it.
