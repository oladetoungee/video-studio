Study one page before you start any non-fiction book. It takes a few minutes.

01 / 08
“So what was that book about?”

Weeks after you finish a non-fiction book, you can give the gist and one or two points. Not much more.

You remember a feeling about the book, not the book itself.
The fix happens before you read →
02 / 08
Read the
structure
first.

Before page one, spend a few minutes on the contents page. Learn the chapter titles by heart if you can. Guess what each will say, then read to check.

An old idea: Mortimer Adler described it in How to Read a Book (1940).
