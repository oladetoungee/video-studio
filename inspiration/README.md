## Adding new inspiration

1. Drop the JPG/PNG into the right subfolder — filename doesn't matter, whatever the phone exported.
2. If a sample teaches a **specific technique** (a font choice, a compositing trick, an animation idea), add a one-line note in this file or as an adjacent `.txt` with the same base name.

## Patterns already captured (from `youtube-slides/`)

- One word per slide, ride on solid color or one big photo
- Movie-poster typography — stacked chunky display type with a single accent word in a warm color
- Real photographs as backgrounds — cinematic, dark vignette
- Brush-stroke highlights behind single accent words (yellow on dark)
- Solid-color transition slides (pure red, dark olive, black) with one short phrase centered
- Photograph + giant text overlay (movie poster + subtitle)
- Color-graded sentences — multiple words of a sentence colored differently for rhythm
- Pastel illustrated scenes with bold serif headlines
